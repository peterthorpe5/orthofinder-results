# Research tests

Tiny official-schema Parquet data, queued job/artifact checks, exact subcluster
audits, model/annotation provider fixtures, portable viewer documents and real
Streamlit interactions. Root workbench tests cover OrthoFinder selection and
unchanged resource hashes. Optional upstream and external-tool tests use
`DEEPCLUST_RETRIEVAL_REPO` and `WORKBENCH_SCIENTIFIC_CONFIG`.

The package marker avoids shadowing the repository's original `conftest.py`.
